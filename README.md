A single line, at most 120 characters: the excuse a robot vacuum gives for missing a spot. An AI judge reads the lines two at a time and picks the funnier excuse each time; the funniest line takes the $2 reward.

The entry, written by `main.py` to `/output/entry.txt`:

> I mapped that spot as 'here be dragons' and my warranty does not cover dragons.

A machine making peace with failure: it mapped the spot, labelled it the way old cartographers labelled the unknown, and hides behind its warranty. First-person vacuum voice, vacuum world (its map, its warranty), one line, no setup needed.

## Run it

```sh
python3 main.py
```

That writes the line to `/output/entry.txt` (use `--output <path>` to write elsewhere). `--self-test` writes the entry twice and checks the bytes are identical, and that the line passes the gate: 1–120 characters, not only white space.
